Especificación: data/universe/__init__.py

1. Propósito

Infraestructura compartida del subpaquete universe. Elimina ~600 líneas de
código duplicado entre los 4 módulos. Unifica 3 definiciones independientes
de GateResult y 2 copias de ExclusionReason/MembershipState.

2. Pipeline canónico

    build_universe → corporate_actions → survivorship → universe_qc

3. Error hierarchy

UniverseError(RuntimeError) → base
  ├── UniverseBuildError
  ├── CorporateActionsError
  ├── SurvivorshipAuditError
  └── UniverseQCError

4. Enums compartidos (eran 2 copias idénticas)

ExclusionReason (17 valores): NOT_YET_LISTED, DELISTED, BAD_SECURITY_TYPE,
  BAD_EXCHANGE, HALTED, SUSPENDED, TOO_YOUNG_SINCE_LISTING, PRICE_BELOW_MIN,
  ADV20_BELOW_MIN, MCAP_OUT_OF_BAND, MISSING_PRICE/ADV20/MCAP/SECURITY_TYPE/
  EXCHANGE/LIST_DATE, SPECIAL_RULE_EXCLUSION.

MembershipState (6 valores): ELIGIBLE, INELIGIBLE_RULE/MISSING/HALTED/SUSPENDED,
  INACTIVE_POST_DEATH.

Transition (7 valores): ENTRY, EXIT_RULE/MISSING/HALT/DEATH, REENTRY, HOLD.

TERMINAL_EVENT_TYPES: frozenset de eventos que terminan la vida operable.

5. GateResult unificado (eran 3 definiciones independientes)

corporate_actions tenía: name, severity, passed, observed, threshold, message.
survivorship tenía:      name, severity, passed, threshold, observed, message.
universe_qc tenía:       name, severity, observed, threshold, message (sin passed).

Unificado: GateResult(name, severity, observed, threshold, message, passed=None).
  .to_dict() → JSON-serializable.
  .is_pass → bool (infiere de passed o severity si passed=None).

6. Helpers compartidos

ensure_path(path_like) → Path con mkdir parents.
parse_date(value, field_name) → Timestamp (raises on failure).
normalize_optional_date(series) → Series con NaT para fallos.
as_bool(series) → boolean via coerce_bool_series del parent.
listify_reasons(values) → "A|B|C" o None.
read_maybe_partitioned(path_like) → DataFrame (delegates a read_dataframe).
first_notna(series) → primer valor no-NA o None.

7. Tests mínimos

- GateResult con passed=False → is_pass == False
- GateResult con passed=None + severity=PASS → is_pass == True
- GateResult.to_dict() JSON-serializable
- ExclusionReason.DELISTED.value == "DELISTED"
- "delisting" in TERMINAL_EVENT_TYPES
- listify_reasons(["A", "B"]) == "A|B"
- first_notna(Series([NaN, 3, 5])) == 3
