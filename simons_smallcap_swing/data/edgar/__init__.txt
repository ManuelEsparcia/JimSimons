Especificación: data/edgar/__init__.py

1. Propósito

Infraestructura compartida del subpaquete EDGAR. Elimina ~750 líneas de
código duplicado entre los 7 módulos del pipeline SEC. Proporciona
abstracciones HTTP compartidas para cumplir rate limits de SEC.

2. Pipeline canónico

    ticker_cik → fetch_submissions → fetch_companyfacts
    → parse_xbrl → point_in_time → filings_flags → edgar_qc

Cada paso es ejecutable standalone con CLI. Los datos fluyen
como parquet/JSON entre pasos.

3. Error hierarchy

EdgarError(RuntimeError) → base
  ├── InputValidationError(ValueError)
  └── PayloadSchemaError

4. CIK normalization (era 7 copias)

normalize_cik(value) -> str: zero-padded 10 dígitos. "320193" → "0000320193".
normalize_symbol(value) -> str: upper stripped.

5. SEC HTTP client (era 2 copias independientes)

RateLimiter(min_interval=0.11): token-bucket para ≤9 req/s (SEC limit 10).
SecClientConfig: user_agent, rate_per_second, max_retries, backoff_*.
sec_fetch_json(url, config, rate_limiter) -> (url, payload, status, attempts, error).
sec_backoff_sleep(attempt, config): exponential backoff con jitter.

6. Date/numeric parsing (era 3+ copias)

parse_date(value) -> Optional[str]: ISO YYYY-MM-DD.
parse_datetime_utc(value) -> Optional[Timestamp]: UTC-normalised.
safe_to_datetime(series) -> Series: coerce con NaT.
parse_numeric(value) -> Optional[float]: finite o None.
parse_boolish(value) -> Optional[bool]: true/1/yes/t conventions.
safe_str(value) -> Optional[str]: stripped o None.

7. Column resolution

normalize_columns(df, aliases) -> DataFrame: rename por alias mapping.
maybe_rename_columns: alias backward compat.

8. Config/run helpers

config_hash(payload) -> str (16 chars): hash de config para audit.
normalize_run_id(value) -> str.
normalize_asof(value) -> str: ISO format.
ensure_directory(path): mkdir -p.
sanitize_accession_number(value) -> Optional[str]: "0000320193-24-000123".
normalize_metric(value) -> Optional[str]: XBRL tag lowercase.

9. Re-exports de data.__init__

Severity, json_safe, canonical_json, sha256_text, sha256_file,
read_dataframe, write_parquet_safe, write_json_safe, deep_merge, etc.

10. Tests mínimos

- normalize_cik("320193") == "0000320193"
- normalize_cik(None) == ""
- parse_date("2024-01-15") == "2024-01-15"
- parse_date(nan) is None
- config_hash determinista: misma config → mismo hash
- RateLimiter.acquire() introduce delay ≥ min_interval
- sanitize_accession_number normaliza formato con dashes
