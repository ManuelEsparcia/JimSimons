Especificación: data/edgar/edgar_qc.py

1. Propósito

QC end-to-end del pipeline EDGAR. Valida cada tabla producida por los
6 módulos upstream: ticker_cik, fetch_submissions, fetch_companyfacts,
parse_xbrl, point_in_time, filings_flags. Produce un veredicto formal
(PASS/WARN/FAIL) con métricas cuantitativas que alimentan el gate de
promoción del pipeline de datos.

2. Tablas que valida

  ticker_cik: CIK unique, no nulls, zero-padded 10d.
  submissions: accession unique, dates valid, form_type non-null.
  companyfacts: (cik, taxonomy, concept, unit, period) non-null.
  parsed_xbrl: canonical_metric mapped, values finite.
  point_in_time: PIT invariant (filed_date < asof), staleness bounded.
  filings_flags: flags coherent (is_late requires deadline_date).

3. Dimensiones de QC

Stage coverage:
  ¿Cuántos CIKs pasaron cada stage? ¿Cuántos se perdieron?
  StageCoverageThresholds: min_cik_fraction por stage.

Identity:
  CIK format válido, symbol non-null, no duplicados en current mapping.
  IdentityThresholds: max_duplicate_fraction, max_null_symbol_fraction.

Value quality:
  Valores financieros finite, sin outliers extremos (revenue negativa
  cuando no aplica), unidades coherentes.
  ValueQualityThresholds: max_inf_fraction, max_extreme_outlier_fraction.

Lineage:
  Cada fact tiene accession_number que existe en submissions.
  LineageThresholds: max_orphan_fact_fraction.

Staleness:
  Distribución de staleness_days en el panel PIT.
  StalenessThresholds: max_stale_fraction, stale_days_threshold.

4. Scoring

ScoreWeights: weight por dimensión (coverage, identity, value, lineage, staleness).
ScoreThresholds: score_pass, score_warn.
Weighted average → overall score → PASS/WARN/FAIL.

5. Check pattern

make_check(name, severity, passed, metric_value, threshold, message, details):
  Produce un check record estandarizado.
  checks = list[dict] con: name, severity, passed, metric, threshold, msg.

6. EdgarQCConfig

coverage_thresholds: StageCoverageThresholds
identity_thresholds: IdentityThresholds
value_quality_thresholds: ValueQualityThresholds
lineage_thresholds: LineageThresholds
staleness_thresholds: StalenessThresholds
score_weights: ScoreWeights
score_thresholds: ScoreThresholds

7. Output

edgar_qc_{run_id}.json: checks, scores, summary, config_hash.
edgar_qc_findings_{run_id}.parquet: detalle de findings por CIK/tabla.

8. Gate aggregation

- FAIL en coverage (CIKs missing > threshold) → FAIL overall.
- FAIL en identity (duplicates) → FAIL overall.
- WARN acumula pero no bloquea.
- Overall score < score_pass → FAIL.
- score_pass ≤ overall < score_warn → WARN.

9. Tests mínimos

- CIK con formato inválido → identity FAIL.
- Accession number sin match en submissions → lineage WARN/FAIL.
- 50% CIKs missing en stage → coverage FAIL.
- Staleness > threshold para >X% del panel → staleness WARN.
- Revenue = -1e15 → value quality FAIL (extreme outlier).
- All checks PASS → overall PASS con score > score_pass.
- Pipeline con datos sintéticos limpios → PASS completo.
