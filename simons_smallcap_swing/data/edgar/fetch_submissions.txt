Especificación: data/edgar/fetch_submissions.py

1. Propósito

Descarga y persiste los filing submissions de SEC EDGAR para una lista
de CIKs. Cada submission contiene metadata del filing: form type,
filing date, acceptance datetime, accession number, primary document.
Es el registro temporal de "cuándo SEC aceptó qué filing de quién".

2. API de SEC

Endpoint: https://data.sec.gov/submissions/CIK{cik}.json
- Contiene filings recientes + paginación para históricos.
- Rate limit: 10 req/s con User-Agent obligatorio.
- Responde 429 si se excede el rate.

Usa sec_fetch_json() compartido de edgar.__init__.

3. IngestConfig

user_agent, rate_per_second, max_retries, backoff_*,
cik_list_path, output_dir, asof_date, run_id,
min_filing_date, max_filing_date,
include_form_types (default: all).

4. Pipeline por CIK

Para cada CIK:
  1. fetch_json(url) con retry + rate limiting
  2. Extraer filings recientes + paginar si hay más
  3. Parse: form_type, filing_date, acceptance_datetime, accession_number,
     primary_document, is_xbrl, file_number, size
  4. Persist raw envelope (JSON) + parsed rows (parquet)

5. FetchResult (por CIK)

cik, status (ok/error/skipped), n_filings, n_pages_fetched,
http_status, error_message, elapsed_seconds.

6. Normalización de campos

- acceptance_datetime → parse_datetime_utc (UTC-normalised)
- filing_date → parse_date (ISO string)
- is_xbrl → parse_boolish
- accession_number → sanitize_accession_number
- form_type → safe_str uppercase

7. Output

raw/{asof}/{run_id}/{cik}.json: envelope crudo para replay.
parsed/{asof}/{run_id}/submissions.parquet: tabla normalizada.
manifest.json: run metadata, config_hash, CIK results.

8. Idempotencia

Si raw envelope ya existe para (asof, run_id, cik) y el config_hash
coincide → skip (no re-fetch). Esto permite reintentar runs parciales
sin re-descargar CIKs ya completados.

9. Tests mínimos

- Parse de submission JSON sintético: campos correctos.
- Rate limiter: N requests en T segundos ≤ rate_per_second * T.
- Idempotencia: segundo run con mismo config → skip.
- acceptance_datetime parsed como UTC.
- accession_number normalizado con dashes.
