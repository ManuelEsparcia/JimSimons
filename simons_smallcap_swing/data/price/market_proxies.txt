Especificación: data/price/market_proxies.py

1. Propósito

Construye series de referencia de mercado para el universo: retorno de
mercado (equal/cap-weighted), beta context, benchmarks de sector,
proxies de liquidez y volatilidad agregada. Estas series alimentan
neutralización (labels y portfolio), regime detection, y benchmarking.

2. Proxies producidos

Market return (daily):
  equal_weight_return: media aritmética de retornos del universo.
  cap_weight_return: media ponderada por mcap.
  Modo configurable: solo eligible, o todo el cross-section.

Volatility aggregates:
  market_realized_vol_{N}d: rolling vol del market return (N = 5,10,21,63).
  cross_section_dispersion: std cross-sectional de retornos diarios.

Liquidity:
  median_dollar_volume: mediana de ADV del universo por fecha.
  pct_low_volume: fracción de nombres con volume < threshold.

Breadth:
  advance_decline_ratio: #up / #down por fecha.
  new_highs_lows_ratio: #52w-high / #52w-low.

3. Pipeline

normalize_prices() → normalize_universe() → build_universe_panel()
→ add_symbol_level_derived_columns() → build_market_return_base()
→ compute_daily_proxies() → apply_optional_transforms()
→ validate_output() → persist_outputs()

4. Robust statistics

Usa winsorize_series, robust_mean, robust_std de price.__init__.
Estas son bridge hacia simons_core.math.robust (consolidación pendiente).

compute_daily_proxies() winsoriza retornos antes de agregar para evitar
que un único outlier (delisting return, data error) contamine el proxy.

5. Z-scoring (ZScoreConfig)

Opcinal: z-score de proxies para stationarity. Window configurable.
z(t) = (x(t) - robust_mean(x, window)) / robust_std(x, window).

6. Severity classification

classify_proxy_severity(metric, value, thresholds):
  Coverage < 50% → FAIL. Coverage < 80% → WARN.
  Dispersion = 0 → FAIL (no cross-section).
  Volume proxy all-NaN → WARN.

7. Output

market_proxies_{run_id}.parquet: panel (date, proxy_name, value).
market_proxies_warnings_{run_id}.parquet: findings.
market_proxies_summary_{run_id}.json: stats, coverage, severity.

8. Invariantes

I1. Market return no usa datos futuros (rolling backward-looking).
I2. Cap-weighted return usa mcap known at t (PIT mcap).
I3. Proxies definidos para todas las fechas del calendario.
I4. Winsorización antes de agregación (nunca al revés).

9. Tests mínimos

- Equal-weight return de [+1%, -1%, +1%] = +0.33%.
- Cap-weighted con mcaps [100, 200, 300] y rets [1%, 2%, 3%] correcto.
- Outlier de +500% winsorizado antes de mean → mean razonable.
- Dispersion = 0 cuando todos los retornos son iguales.
- Coverage < 50% → severity FAIL.
