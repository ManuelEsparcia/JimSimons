Especificación: data/price/__init__.py

1. Propósito

Infraestructura compartida del subpaquete price. Elimina duplicación
de utilidades entre los 4 módulos del pipeline de precios.

2. Pipeline canónico

    fetch_prices → qc_prices → adjust_prices → market_proxies

3. Error hierarchy

PriceError(RuntimeError) → base
  ├── PriceAdjustmentError
  ├── FetchPricesError
  ├── ProviderError → RetriableProviderError, PermanentProviderError
  ├── QCPricesError
  └── MarketProxiesError

4. CanonicalEventType enum (17 valores)

SPLIT, REVERSE_SPLIT, STOCK_DIVIDEND, CASH_DIVIDEND, SPECIAL_CASH_DIVIDEND,
TICKER_CHANGE, NAME_CHANGE, SHARE_CLASS_CHANGE, EXCHANGE_CHANGE,
MERGER, ACQUISITION, SPINOFF, RIGHTS_ISSUE, TENDER_OFFER,
DELISTING, RELISTING, BANKRUPTCY_REORG.

5. Column candidates

DATE_CANDIDATES, SYMBOL_CANDIDATES, OHLCV_CANDIDATES (dict con open/high/low/close/volume).

6. Price helpers

parse_iso_ts(value) → Optional[Timestamp].
normalize_timestamp_series(series) → UTC-normalised.
build_symbol_key(df) → Series uppercase symbol.
coerce_float_columns(df, columns) → pd.to_numeric coercion.

7. Robust statistics (bridge hacia simons_core.math.robust)

winsorize_series(s, lower_q=0.01, upper_q=0.99).
robust_mean(s, lower_q, upper_q) → float.
robust_std(s, lower_q, upper_q) → float.
median_or_nan(s) → float.

8. QC helpers

Gate enum: PASS, WARN, FAIL.
concat_findings(frames) → DataFrame concatenado sin vacíos.

9. Re-exports de data.__init__

Severity, json_safe, canonical_json, sha256_text, read_dataframe,
write_parquet_safe, write_json_safe, deep_merge, etc.

10. Tests mínimos

- CanonicalEventType.SPLIT.value == "split"
- winsorize_series clips outliers correctamente
- robust_mean con outlier extremo ≈ media sin outlier
- build_symbol_key resuelve "symbol" o "ticker" o "instrument_id"
- concat_findings con DataFrames vacíos → DataFrame vacío
