Especificación: simons_core/math/robust.py

1. Propósito

Estadísticas robustas univariadas para inputs financieros ruidosos y con
colas pesadas. Median + MAD, z-scoring robusto, trimmed mean, winsorización,
Huber reweighting. Para features cross-sectional de small caps.

2. Convenciones

- NaN policy: "omit" (default) o "raise". Explícito y determinista.
- Consistency modes para MAD scaling:
    "raw"       default. MAD sin escalar. Conservador. Nunca infla z-scores.
    "normal"    MAD * 1.4826. Correcto solo bajo gaussianidad.
    "empirical" max(MAD*1.4826, IQR/1.349). Nunca subestima dispersión.
- Escala degenerada (MAD ≈ 0) -> floor a eps, z-scores = 0.0.
- Outputs vectoriales preservan shape; posiciones no-finitas -> NaN.

3. Constantes

MAD_NORMAL_CONSISTENCY = 1.482602218505602  (1/Phi^{-1}(0.75))
IQR_NORMAL_CONSISTENCY = 1.3489795003921634  (IQR/sigma bajo N(0,1))
DEFAULT_EPS = 1e-12
DEFAULT_HUBER_C = 1.345
BREAKDOWN_POINT_MEDIAN = 0.50
BREAKDOWN_POINT_MAD = 0.50

4. API pública

robust_center_scale(x, nan_policy="omit", consistency="raw", eps) ->
    (center, scale, meta)
  center = median(x_finite)
  mad_raw = median(|x_finite - center|)
  scale depende de consistency:
    raw: mad_raw
    normal: MAD_NORMAL_CONSISTENCY * mad_raw
    empirical: max(mad_normal, IQR / IQR_NORMAL_CONSISTENCY)
  meta incluye: n_valid, degenerate_scale, breakdown_point, small_sample_note

robust_zscore(x, nan_policy="omit", consistency="raw", eps, clip=None) ->
    ndarray
  z = (x - center) / scale. Degenerado -> 0. NaN preservados. Clip opcional.

robust_clip(x, k=3, nan_policy="omit", consistency="raw", eps) -> ndarray
  Clip a median ± k*scale. Adaptativo al centro y dispersión real.

contamination_fraction(x, k=3, ...) -> (fraction, meta)
  % de observaciones fuera de ±k*scale. Diagnóstico de feature quality.
  <5% normal. >10% feature rota o régimen shift.

trimmed_mean(x, p=0.05, nan_policy="omit") -> (value, meta)
  Symmetric trim. 0 <= p < 0.5.

winsorize(x, lower_q=0.05, upper_q=0.95, nan_policy="omit") -> ndarray
  Quantile clipping. Preserva shape. NaN preserved.

huber_psi(residuals, c=1.345) -> ndarray
  psi(r) = r si |r| <= c, c*sign(r) si |r| > c.

huber_weights(residuals, c=1.345) -> (weights, meta)
  w = min(1, c/|r|). meta.n_downweighted.

5. Por qué default consistency="raw" (CAMBIO IMPORTANTE)

Con "normal" (viejo default), el factor 1.4826 asume gaussianidad.
Small-cap daily returns tienen excess kurtosis 5-20.
Efecto: MAD*1.4826 SUBESTIMA la dispersión real, produciendo z-scores
INFLADOS. Features parecen más extremas de lo que son -> señales falsas
de momentum/reversión -> overfitting.

Con "raw": z-scores más conservadores, menos señales falsas, features
más honestas. El precio es que la escala no es comparable con sigma
directamente, pero para ranking cross-sectional eso no importa.

Con "empirical": usa IQR como safety net para datos donde MAD colapsa
(>50% de valores idénticos, común en features con muchos ceros).
Recomendado para features/cross_sectional.py.

6. Invariantes

I1. robust_center_scale("raw") <= robust_center_scale("normal") (scale)
I2. robust_center_scale("empirical") >= robust_center_scale("normal")
I3. robust_zscore con escala degenerada -> array de ceros (no Inf)
I4. robust_clip preserva non-outlier values exactamente
I5. contamination_fraction ∈ [0, 1]
I6. trimmed_mean(p=0) == mean de finitos

7. Tests mínimos

- Default consistency es "raw"
- [1,2,2,3,100]: center=2, scale_raw=1.0
- scale_empirical >= scale_normal para datos contaminados
- robust_zscore con constant -> zeros
- robust_clip(k=3) reduce outlier de 100 a < 100
- contamination_fraction([1,2,2,3,100], k=3) > 0
- contamination_fraction de datos clean -> 0
- huber_weights([0,1,2], c=1) = [1, 1, 0.5]
