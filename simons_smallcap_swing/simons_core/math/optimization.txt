Especificación: simons_core/math/optimization.py

1. Propósito

Optimización convexa QP para portfolio construction. Formulación canónica
con turnover L1, PSD regularization, solver waterfall, certificación KKT.
El cambio más importante: turnover penalty acepta costes per-asset.

2. Problema canónico

    minimize_w   0.5 * w' Q w + c' w + sum_i cost_i * |w_i - w_prev_i|

    subject to   C @ w <= d
                 E @ w  = f
                 lb <= w <= ub

El último término modela turnover con costes per-asset vía epigraph:
    t >= 0,  w - w_prev - t <= 0,  -w + w_prev - t <= 0

3. Per-asset transaction costs (CAMBIO CLAVE)

turnover_penalty acepta:
  - float scalar: λ * sum|w_i - w_prev_i| (uniforme, backward compatible)
  - ndarray(n,): sum_i cost_i * |w_i - w_prev_i| (per-asset, correcto)

Para small caps, cost_i = spread_bps_i + impact_bps_i + commission_bps_i.
AAPL: ~1bp. Micro-cap ilíquida: ~50bp. Sin per-asset costs, el optimizer
sobreopera en names ilíquidos -> degradación de 200-400bps/año en ejecución.

4. API pública

solve_qp(Q, c, C=None, d=None, E=None, f=None, lb=None, ub=None,
         w_prev=None, turnover_penalty=0.0, ...) -> dict
solve_qp_result(...) -> QPSolution

validate_qp_inputs(...) -> dict de arrays normalizados
build_turnover_epigraph(w_var, w_prev, turnover_penalty) -> TurnoverEpigraph
compute_kkt_residuals(...) -> KKTDiagnostics
project_to_simplex(z) -> ndarray

5. Tipos estructurados

SolverConfig:        solver_order, eps_abs, eps_rel, max_iters, verbose
SolverAttempt:       solver, status, solve_time_sec, error_message
ConditioningReport:  lam_min/max raw/reg, kappa_q, is_psd_raw, is_convex_usable
KKTDiagnostics:      21 campos de residual, max_residual, is_certified
QPSolution:          x_opt, objective_value, conditioning, kkt, attempts, meta
TurnoverEpigraph:    t_var, objective_term, constraints (3)

6. Solver waterfall

Default: OSQP -> CLARABEL -> SCS. Configurable via SolverConfig.
Si ninguno produce status "optimal" o "optimal_inaccurate" -> SolverFailureError.
Infeasible/Unbounded -> raise inmediato sin intentar siguiente solver.
accept_inaccurate=True por defecto (tolerance-compliant suboptimal accepted).

7. Hessian conditioning

Q_sym = 0.5 * (Q + Q')
eigvals = eigvalsh(Q_sym)
delta = min(max(reg_eps - lam_min, 0), reg_max)
Q_reg = Q_sym + delta * I
kappa = lam_max_reg / lam_min_reg
Si kappa > cond_max -> ConditioningError

8. KKT certification

21 residuales: primal feasibility, dual feasibility, complementarity,
stationarity, plus 10 turnover-specific residuals.
is_certified = all(residual <= kkt_tol and finite)

9. Invariantes

I1. Scalar turnover_penalty produce resultados idénticos a versión original.
I2. Vector turnover_penalty no-negative elementwise.
I3. Al menos un entry del vector debe ser > 0 para epigraph construction.
I4. Q regularizado es PSD con kappa <= cond_max o falla.
I5. project_to_simplex: sum = 1, all >= 0.
I6. CVXPY no instalado -> SolverUnavailableError (fail-fast, no silent).

10. Tests mínimos

- validate_qp_inputs con scalar turnover_penalty: OK
- validate_qp_inputs con vector turnover_penalty: OK
- validate_qp_inputs con negative cost entry -> InvalidProblemError
- validate_qp_inputs con wrong-length vector -> InvalidProblemError
- project_to_simplex: sum ≈ 1, all >= 0
- enforce_box_constraints: output within bounds
- KKT residuals con solución exacta conocida -> is_certified
- solve_qp tiny (si CVXPY disponible): status=optimal, x ≈ [0.5, 0.5]
