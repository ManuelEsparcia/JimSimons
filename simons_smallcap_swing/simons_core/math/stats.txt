Especificación: simons_core/math/stats.py

1. Propósito

Métricas financieras institucionales y estadísticas descriptivas para
research, validación y backtest. Cada métrica tiene definición explícita,
convención de anualización documentada y manejo determinista de NaN/Inf.

2. Convenciones generales

- NaN handling: omit (no silent zero-imputation). Finite observations only.
- Annualisation: sqrt(periods_per_year) para ratios. periods_per_year=252.
- ddof=1 por defecto (sample, no population).
- eps=1e-12 como floor para divisiones.
- Simple returns convention: r_t = P_t/P_{t-1} - 1. Válidos en [-1, +inf).

3. API pública — Descriptivas

nanmean1d(x) -> float
nanvar1d(x, ddof=1) -> float
nanstd1d(x, ddof=1) -> float
sem1d(x, ddof=1) -> float
rolling_mean(x, window, min_periods=None) -> Series
rolling_std(x, window, ddof=1, min_periods=None) -> Series
rolling_zscore(x, window, ddof=1, min_periods=None, eps) -> Series

4. API pública — Correlación

pearson_corr(x, y, ddof=1, eps) -> float (pairwise-finite)
spearman_corr(x, y, ddof=1, eps) -> float (average ranks for ties)
spearman_ic(scores, fwd_returns) -> float (alias de spearman_corr)

5. API pública — Performance metrics (THE MONEY LINE)

sharpe_ratio(returns, rf=0, periods_per_year=252, ddof=1):
  SR = mean(excess) / std(excess) * sqrt(P). IID, sin corrección AC.

sharpe_ratio_adjusted(returns, rf=0, ..., max_lag=None):
  Lo (2002). SR_adj = (mu/sigma) * q / sqrt(eta(q)).
  eta(q) = q + 2 * sum_{k=1}^{q-1} (q-k) * rho_k.
  Corrige sobreestimación por autocorrelación positiva en small caps.
  max_lag default: min(q-1, n//3).

deflated_sharpe_ratio(observed_sr, sr_benchmark=0, n_trials=1, n_obs=252,
                       skewness=0, kurtosis_excess=0):
  Bailey & López de Prado (2014). DSR = Phi((SR - E[max SR|N]) / std(SR)).
  Var(SR) ajustada por skewness y kurtosis (Mertens 2002).
  DSR > 0.95 -> señal probablemente real. DSR < 0.50 -> probablemente ruido.
  Dependencia: scipy.stats.norm (importación diferida).

sortino_ratio(returns, target=0, periods_per_year=252):
  downside_dev = sqrt(mean(min(r-target, 0)^2)).
  target=0 por defecto. Para swing 30% anual, usar target ≈ 0.00104/día.

information_ratio(returns, benchmark, periods_per_year=252, ddof=1):
  IR = mean(active) / tracking_error * sqrt(P). Active = r - benchmark.

omega_ratio(returns, threshold=0):
  sum(max(r-L,0)) / sum(max(L-r,0)). Usa toda la distribución.
  Omega > 1.0 -> más upside que downside vs threshold.

6. API pública — Drawdown

drawdown_series(returns) -> ndarray:
  DD_t = W_t / max_{u<=t}(W_u) - 1. Siempre <= 0.

max_drawdown(returns) -> float: min(drawdown_series)

drawdown_details(returns) -> DrawdownDetails:
  peak_index, trough_index, recovery_index, duration, recovery_duration.

7. API pública — Compound/ratio

cagr(returns, periods_per_year=252):
  W_T^(1/years) - 1. Terminal wealth=0 -> -1.0.

calmar_ratio(returns, ..., method="cagr"):
  Default "cagr" (estándar institucional, Young 1991).
  "annual_mean" disponible como opción explícita.

hit_ratio(returns, threshold=0): fraction con r > threshold.
profit_factor(returns, threshold=0): gross_profit / gross_loss.
tail_ratio(returns, upper_q=0.95, lower_q=0.05): P95 / |P5|.

8. Invariantes

I1. Todas las funciones retornan NaN (no raise) con input vacío o insuficiente.
I2. sharpe_ratio_adjusted(max_lag=0) == sharpe_ratio (exacto).
I3. Para AC positiva: sharpe_adjusted <= sharpe_iid.
I4. deflated_sharpe_ratio ∈ [0, 1].
I5. Con más n_trials, DSR decrece (más probable que SR sea ruido).
I6. calmar default es "cagr", no "annual_mean".
I7. hit_ratio ∈ [0, 1]. profit_factor >= 0. tail_ratio >= 0.
I8. drawdown_series <= 0 en posiciones finitas.
I9. Simple returns < -1.0 -> InvalidInputError (wealth negativa).

9. Tests mínimos

- sharpe_adjusted(max_lag=0) == sharpe_ratio con tolerancia 1e-10
- Serie con AC positiva: sharpe_adjusted < sharpe_iid
- deflated_sharpe(SR=2.0, n_trials=1) > deflated_sharpe(SR=2.0, n_trials=100)
- deflated_sharpe(SR=0.3, n_trials=1000, n_obs=60, kurtosis=10) < 0.5
- calmar default method == calmar(method="cagr")
- hit_ratio([0.01, -0.02, 0.03, -0.01, 0.02]) == 0.6
- profit_factor > 0 para returns con ganancia neta
- drawdown max_drawdown([0.10, -0.20, 0.05, -0.10, 0.20]) ≈ -0.244
- sortino con target=0 y todos positivos -> NaN (no downside)
- omega_ratio con threshold=0 y ganancia neta -> > 1.0
