Especificación: simons_core/interfaces.py

1. Propósito

Capa contractual del pipeline cuantitativo. Define tipos de ejecución,
contenedores semánticos I/O, contratos abstractos de etapa, jerarquía de
errores y guards anti-look-ahead. No implementa lógica de negocio.

2. Cadena abstracta del pipeline

    DataProvider.fetch(asof_date, ctx) -> PriceData
    FeatureBuilder.build(PriceData, ctx) -> FeatureMatrix
    ModelTrainer.fit(FeatureMatrix, Labels|MultiLabels, ctx) -> ModelArtifact
    ModelTrainer.predict(FeatureMatrix, ModelArtifact, ctx) -> PredictionFrame
    PortfolioEngine.rebalance(PredictionFrame, ctx) -> PortfolioDecision
    Validator.validate(artifact, ctx) -> GateResult

Composición válida: output(Stage_i) ⊨ input(Stage_{i+1})

3. Tipos de ejecución

RunContext(frozen=True):
  run_id, asof_date, seed, config_hash, pipeline_version, market,
  parent_run_id, artifacts_dir, metadata
  - asof_date normalizado a tz-naive pd.Timestamp
  - metadata congelado como MappingProxy
  - child() preserva lineage y artifacts_dir
  - artifacts_path property devuelve Path o None

GateResult(frozen=True):
  passed, score ∈ [0,1], threshold ∈ [0,1], reasons, metrics, metadata
  - Invariante algebraica: passed == (score >= threshold)
  - from_score() factory classmethod
  - combine(*gates) AND semántico: worst score, all must pass

4. Contenedores I/O

PriceData:       asof_date + DataFrame + anti-look-ahead en __post_init__
FeatureMatrix:   asof_date + DataFrame + Inf audit + NaN ratio warnings
Labels:          asof_date + Series (single target)
MultiLabels:     asof_date + DataFrame (multi-horizon: 5d, 10d, 20d)
                 target_columns, primary_target, to_labels() para backward compat
ModelArtifact:   model_ref + artifact_path + validate_path flag
PredictionFrame: asof_date + DataFrame + score_columns
PortfolioDecision: timestamp + weights Series + long/short/net/gross exposure

5. Jerarquía de errores

ContractViolation (base)
  ├── DataLeakageError          dato futuro detectado
  ├── SchemaViolation           estructura incorrecta
  ├── FeasibilityError          cartera infactible
  ├── ReproducibilityError      contexto no reproducible
  ├── GateSemanticsError        gate inconsistente
  ├── AlignmentError            objetos desalineados
  └── ContractVersionError      versión incompatible

6. Guards (funciones libres)

ensure_no_future_data(frame, asof_date):  anti-look-ahead en DataFrame
ensure_index_aligned(left, right):        indices idénticos
ensure_same_asof_date(*objects):          asof_date compartido
ensure_single_effective_timestamp(df):    una sola fecha en señales
ensure_numeric_frame(df):                 todas las columnas numéricas
ensure_numeric_series(series):            serie numérica
ensure_reproducible_run_context(ctx):     run_id, seed, config_hash no vacíos

7. Validadores de contrato (reutilizables por implementaciones)

validate_provider_output, validate_feature_builder_output,
validate_trainer_inputs (acepta Labels | MultiLabels),
validate_prediction_output, validate_portfolio_output, validate_gate_output

8. Invariantes críticos

I1. Ningún contenedor I/O puede construirse con datos post-asof_date.
I2. FeatureMatrix rechaza Inf en construcción (siempre un bug upstream).
I3. FeatureMatrix emite NaN warnings en metadata si ratio > max_nan_ratio.
I4. ModelArtifact valida existencia del path si validate_path=True.
I5. GateResult.combine falla si algún gate falla (AND estricto).
I6. ModelTrainer.fit acepta Labels o MultiLabels en firma ABC.
I7. PortfolioDecision expone n_longs, n_shorts, long_exposure, short_exposure.

9. Tests mínimos

- RunContext frozen, child preserva lineage, artifacts_dir propagado
- GateResult inconsistente (passed=True, score=0.3, threshold=0.8) -> raise
- GateResult.combine con mix pass/fail -> combined.passed == False
- PriceData con fecha futura -> DataLeakageError
- FeatureMatrix con Inf -> SchemaViolation
- FeatureMatrix con 60% NaN -> warning en metadata, no raise
- MultiLabels.to_labels() devuelve Labels válido
- ModelArtifact(validate_path=True) con path inexistente -> SchemaViolation
- validate_trainer_inputs con MultiLabels: verifica alignment
