Especificación: simons_core/calendar.py

1. Propósito

Fuente de verdad temporal del stack para US equities. Opera sobre sesiones
reales de mercado (NYSE/NASDAQ), no sobre business days genéricos. Timezone
canónica: America/New_York. Backend: exchange_calendars (encapsulado).

2. Modelo formal

    S = {s_1 < s_2 < ... < s_n}  sesiones válidas, ordenadas y únicas

Operaciones sobre S:
    next_trading_day(d, n)   -> s_{k+n-1}  (k = primera sesión > d)
    prev_trading_day(d, n)   -> s_{k-(n-1)}  (k = última sesión < d)
    trading_days_between(a,b,inclusive) -> |S ∩ [a,b]| según semántica
    align_to_session(ts, mode) -> timestamp alineado a sesión
    trading_days_array(a,b,inclusive) -> DatetimeIndex de sesiones

3. MarketCalendar (frozen dataclass)

Campos:
  market, timezone, sessions (DatetimeIndex tz-naive), opens (tz-aware),
  closes (tz-aware), session_types (Series optional), backend_name

Propiedades:
  first_session, last_session, coverage, schedule, n_sessions

Métodos:
  is_trading_day, session_open, session_close, session_type,
  is_early_close, session_duration_minutes,
  next_trading_day, prev_trading_day, trading_days_between,
  trading_days_array, align_to_session

4. SessionType enum

  REGULAR, EARLY_CLOSE, HALF_DAY, SPECIAL

5. Semánticas estrictas

next_trading_day: estrictamente posterior a d. n >= 1.
prev_trading_day: estrictamente anterior a d. n >= 1.
trading_days_between: 4 modos (left, right, both, neither).
  left  -> [start, end)
  right -> (start, end]
  both  -> [start, end]
  neither -> (start, end)
align_to_session:
  next_open   -> primer open >= ts
  prev_close  -> último close <= ts
  session_label -> etiqueta de sesión tz-aware

6. Normalización

- Naive timestamps -> tz_localize(America/New_York, ambiguous="raise")
- Tz-aware -> tz_convert(America/New_York)
- Session labels -> tz-naive midnight (separate de opens/closes tz-aware)
- DST transitions -> TimestampNormalizationError si ambiguo

7. Nuevos métodos (v1.1)

is_early_close(date_like) -> bool:
  True si EARLY_CLOSE o HALF_DAY. Para fill simulation y impact models.

session_duration_minutes(date_like) -> float:
  Usa opens/closes reales. Regular=390, Thanksgiving Friday=210.

trading_days_array(start, end, inclusive) -> DatetimeIndex:
  Batch de sesiones entre dos fechas. Para ejes de backtest, label horizons.

8. Fail modes

- n <= 0 en next/prev -> ValueError
- Rango invertido en between -> ValueError
- Fecha fuera de cobertura -> CalendarRangeError
- Mercado no soportado -> UnsupportedMarketError
- DST ambiguo -> TimestampNormalizationError

9. Tests mínimos

- next_trading_day desde viernes -> lunes (o siguiente hábil)
- prev_trading_day desde lunes -> viernes previo
- trading_days_between con los 4 modos de inclusividad
- align_to_session en cada modo
- is_early_close en Thanksgiving Friday -> True
- session_duration_minutes regular -> 390.0
- trading_days_array devuelve DatetimeIndex ordenado y único
- n=0 en next_trading_day -> ValueError
- Fecha fuera de rango -> CalendarRangeError
