Especificación: simons_core/__init__.py

1. Propósito

Fachada pública del paquete simons_core. Expone 25 símbolos estables mediante
lazy loading (cero side effects al importar). Todo lo demás es accesible via
import directo del submódulo correspondiente.

2. Superficie pública (25 símbolos, 4 tiers)

Tier 1 — Contexto de ejecución:
  RunContext, GateResult

Tier 2 — Contenedores I/O:
  PriceData, FeatureMatrix, Labels, MultiLabels,
  ModelArtifact, PredictionFrame, PortfolioDecision

Tier 3 — Contratos abstractos:
  DataProvider, FeatureBuilder, ModelTrainer, PortfolioEngine, Validator

Tier 4 — Servicios fundacionales:
  DataSchema, validate_schema, assert_schema, get_schema, list_schemas,
  MarketCalendar, load_market_calendar,
  get_logger, with_step,
  ContractViolation, CONTRACT_VERSION

3. Qué NO está en el root

Errores específicos (DataLeakageError, SchemaViolation, etc.):
  from simons_core.interfaces import DataLeakageError

Schemas canónicos (PRICE_ADJUSTED_SCHEMA, UNIVERSE_SCHEMA, etc.):
  from simons_core.schemas import PRICE_ADJUSTED_SCHEMA

Sinks de logging (MemorySink, StreamJsonSink, etc.):
  from simons_core.logging import MemorySink

Helpers de guard (ensure_no_future_data, ensure_numeric_frame, etc.):
  from simons_core.interfaces import ensure_no_future_data

4. Mecanismo

__getattr__ + _EXPORT_MAP resuelve imports lazily y los cachea en globals().
TYPE_CHECKING block proporciona soporte para IDE/mypy sin coste de import.

5. Invariantes

I1. import simons_core no ejecuta I/O, no toca disco, no configura logging.
I2. Cada símbolo en __all__ tiene entrada en _EXPORT_MAP.
I3. __all__ es la fuente de verdad de la API pública.
I4. Eliminar un símbolo de __all__ requiere major version bump.

6. Tests mínimos

- Todos los símbolos en __all__ son resolvibles via getattr.
- Símbolos eliminados del root (MemorySink, etc.) levantan AttributeError.
- Símbolos eliminados siguen accesibles via import directo del submódulo.
- dir() es consistente con __all__.
