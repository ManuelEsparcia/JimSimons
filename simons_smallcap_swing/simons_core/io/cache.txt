Especificación: simons_core/io/cache.py

1. Propósito

Cache local determinista para el stack. Acelera recomputación preservando
equivalencia semántica: cache hit == recomputar con mismos inputs.
Operacional, no estadístico: no cambia alpha, labels, riesgo ni portfolio.

2. Garantías

- Keys deterministas basadas en hash criptográfico (SHA-256).
- Escritura atómica: temp file -> fsync -> rename.
- Lectura fail-closed: expiración, corrupción o serializer desconocido -> miss.
- Invalidación explícita por namespace, tag o producer.
- Evicción LRU por byte budget usando mtime como señal de recencia.
- Concurrencia: single-writer / multi-reader. No distributed.

3. Cambio clave: pandas es requerido

Viejo:  try: import pandas except: pd = None (con guards pd is None)
Nuevo:  import pandas (fail-fast si no está)

En un stack quant, pandas siempre está disponible. Los guards pd is None
añadían caminos de ejecución no testeados y complejidad sin beneficio.

4. API pública

LocalCache(root_dir, max_bytes=None, default_ttl=None, ...):
  get(key) -> value | None (miss)
  set(key, value, ttl=None, tags=None, producer=None)
  exists(key) -> bool
  delete(key) -> bool
  clear()
  invalidate_namespace(namespace)
  invalidate_by_tags(tags)
  invalidate_by_producer(producer)
  list_entries(namespace=None) -> list[CacheEntryMetadata]
  stats() -> CacheStatsSnapshot

Funciones de conveniencia (usan default_cache singleton):
  cache_key(...) -> str
  get(key), set(key, value), exists(key), delete(key), clear()
  invalidate_by_tags, invalidate_by_producer, invalidate_namespace
  list_entries, stats

5. Serializers

json:           dict/list/str/int/float -> JSON bytes
pickle:         any Python object -> pickle bytes
pandas_pickle:  DataFrame/Series/Index -> pickle bytes (pandas requerido)
numpy_npy:      ndarray -> npy format bytes
text:           str -> UTF-8 bytes

Auto-detection: DataFrame -> pandas_pickle, ndarray -> numpy_npy,
str -> text, else -> try json, fallback pickle.

6. Cache key

    key = SHA256(canonical_json(namespace, producer, version, params))

canonical_json ordena keys, normaliza types, es determinista.

7. LRU eviction

Si max_bytes está configurado:
  al escribir, si total_bytes > max_bytes:
    ordenar entries por mtime ascendente (least recently used first)
    eliminar entries hasta total_bytes <= max_bytes * 0.9 (10% headroom)

8. Invariantes

I1. get() nunca devuelve datos expirados (TTL respetado).
I2. get() nunca devuelve datos corruptos (integridad verificada).
I3. set() es atómica: partial write no es visible.
I4. Mismo key + mismo value -> idempotente (no duplica).
I5. invalidate_by_tags elimina TODAS las entries con ANY tag match.
I6. stats() refleja hits/misses/evictions desde último reset.

9. Tests mínimos

- set + get roundtrip para cada serializer (json, pickle, pandas, numpy, text)
- TTL expirado -> get retorna None
- Key inexistente -> get retorna None
- Corrupción (bytes modificados) -> get retorna None (fail-closed)
- invalidate_by_tags elimina entries correctas
- LRU eviction: con max_bytes, entries antiguas se eliminan primero
- stats contadores: hits incrementa en hit, misses incrementa en miss
- DataFrame roundtrip preserva dtypes, index y valores
