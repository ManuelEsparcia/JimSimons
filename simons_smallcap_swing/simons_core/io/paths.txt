Especificación: simons_core/io/paths.py

1. Propósito

Resolución determinista de localizadores canónicos para artefactos del stack.
Mapea descriptores lógicos (artifact_class, env, domain, run_id, date) a URIs
de filesystem local o S3. Previene path traversal y leakage de entorno.

2. Layout canónico

    {root}/{artifact_class}/{layout_version}/{domain}/{entity}/{version}/{date}/{run_id}/{partition}/{artifact_name}

Segmentos opcionales se omiten. Root depende del env:
  local -> file:///srv/jimsimons/local
  dev   -> s3://jimsimons-dev
  prod  -> s3://jimsimons-prod
  test  -> file:///tmp/jimsimons-test

3. API pública

build_locator(artifact_class, env, domain=None, ...) -> Locator
build_tmp_locator(env, scope, run_id, ...) -> Locator
build_run_artifact_path(artifacts_dir, stage, artifact_name, ...) -> Path
  Nuevo: conecta RunContext.artifacts_dir con filesystem.
  Layout: {artifacts_dir}/{stage}/{date_str}/{run_id}/{artifact_name}
  Protección contra path traversal vía resolve().relative_to(base).

ensure_run_dir(artifacts_dir) -> Path
  Crea directorio idempotente. Nuevo.

validate_locator(locator, env_roots=None)
normalize_segment(value, kind="generic") -> str
confined_to_root(path, root) -> bool
ensure_parent_dirs(path)
get_root(env, env_roots=None) -> str
locator_from_uri(uri) -> Locator
canonical_descriptor_digest(...)  -> str (sha256 truncado)

4. Segment validation

Regex por kind:
  generic:        [a-z0-9][a-z0-9_-]{0,62}
  date:           YYYY-MM-DD
  version:        v\d+(\.\d+){0,2}
  run_id:         run_[a-z0-9][a-z0-9_-]{2,63}
  digest:         [a-f0-9]{8,64}
  artifact_name:  [a-z0-9][a-z0-9_.-]{0,127}
  partition:      [a-z0-9][a-z0-9_=-]{0,127}

Segmentos reservados: latest, null, none.
Unicode -> NFD + lowercase + strip.
Max URI: 4096 chars.

5. Seguridad

- Path traversal: confined_to_root verifica que path.resolve() está bajo root.
- build_run_artifact_path: resolve().relative_to(base) falla si escapa.
- Segmentos con / \ . .. rechazados por regex.

6. Metrics

get_metrics_snapshot() -> LocatorMetricsSnapshot (contadores de built/resolved)
reset_metrics() -> limpia contadores (thread-safe)

7. Tests mínimos

- build_locator produce URI con todos los segmentos en orden
- build_tmp_locator usa artifact_class="tmp"
- build_run_artifact_path: layout correcto, crea parents
- build_run_artifact_path con ../../../etc/passwd -> PathTraversalError
- ensure_run_dir crea directorio y es idempotente
- normalize_segment con espacios/unicode -> lowercase normalizado
- Segmento con / -> InvalidSegmentError
- Date segment mal formado -> InvalidDateFormatError
