Especificación: labels/neutralized_targets.py

1. Propósito

Transforma targets forward (brutos o netos) en targets neutralizados frente
a exposiciones sistemáticas observables en fecha t. Aísla el componente
idiosincrático del retorno: lo que el modelo debe predecir es alpha, no beta.

Tres metas simultáneas:
- Evitar que el modelo aprenda solo mercado/sector/tamaño/liquidez.
- Mejorar robustez OOS forzando a modelar estructura residual más estable.
- Desacoplar predicción y posicionamiento: la cartera reintroduce riesgos
  sistemáticos en otra capa.

2. Modelo formal

Para cada (fecha t, horizonte h), cross-section de n_t observaciones:

    y_{t,h} = X_t β_{t,h} + ε_{t,h}

    y_neut(i,t,h) = ε(i,t,h) = y(i,t,h) - X_t(i) β̂_{t,h}

Cada fecha se resuelve independientemente. Nunca mezclar fechas.

3. Estimadores soportados (5)

ols:                          OLS puro. Frágil en small caps.
ridge:                        Ridge sin pesos. Estable pero ignora heteroscedasticidad.
weighted_ridge (default):     Ridge con pesos W. Robusto a multicolinealidad +
                              cross-sections irregulares + dummies poco pobladas.
huber:                        M-estimador de Huber. Robusto a outliers.
sector_demean_plus_factor:    Demean por sector + ridge sobre factores residuales.

4. Selección de lambda

fixed (default): lambda_default configurable, versionada.
cv / grid_search_cv: K-fold CV temporal dentro del cross-section.
  Lambda grid: (1e-4, 1e-3, 1e-2, 1e-1, 1.0, 10.0, 100.0)
  cv_min_obs_per_date: mínimo para activar CV (default 50).
  cv_folds: 3 por defecto.

build_labels.py usa grid search con in-sample MSE (inferior).
neutralized_targets.py usa CV proper (correcto). Consolidación pendiente.

5. Exposiciones canónicas

    X_t = [1, sector_dummies, log(mcap), beta_mkt, liquidity_proxy, vol_proxy]

Categóricas: one-hot con min_support. Sectores con < min_support → "OTHER".
Numéricas: se incluyen tal cual, NaN → median imputation dentro del fit.

6. Design matrix validation

- Missing essential fraction: si > max_missing_exposure_ratio → invalidar.
- Near-constant columns: varianza < eps → drop.
- Condition number: si > cond_max (default 1e8) → invalidar (OLS) o proceder (ridge).
- n < n_min_neut → invalidar (cross-section insuficiente).

7. FitResult (por fecha × horizonte)

    success: bool
    failure_reason: str | None
    model_name: str
    lambda_used: float
    residuals: Series (NaN where invalid)
    fitted: Series
    r2, residual_std, residual_var, cond_number, effective_rank
    n_obs_candidate, n_obs_used, dropped_row_frac
    missing_essential_frac, near_constant_frac, min_sector_support
    beta_norm, effective_df
    corr_before: {exposure: corr(y, exposure)} pre-neutralización
    corr_after: {exposure: corr(residual, exposure)} post-neutralización
    diagnostics: dict

8. Política de fallo

neutralization_failure_policy = invalidate_derived_target (default):
  y_base sigue válido. y_neut y derivados → NaN.

Causas de fallo: solve_failed, ill_conditioned, degenerate_residual_variance,
insufficient_cross_section, missing_exposures.

9. Invariantes

I1. Cada fecha se neutraliza independientemente (nunca pool across dates).
I2. PIT estricto: exposiciones en t disponibles antes de t+lag.
I3. y_base siempre se preserva. Neutralización es capa derivada no destructiva.
I4. corr_after[exposure] ≈ 0 si el fit fue exitoso (verificación de sanity).
I5. effective_df < n_obs_used (regularización reduce grados de libertad).
I6. Con lambda → ∞, residual → y - mean(y) (demean puro).
I7. Con lambda → 0, residual → OLS residual.

10. Tests mínimos

- Factor sintético conocido: β̂ ≈ β_true, residuales ≈ ε_true
- Cross-section < n_min_neut → invalidar
- X mal condicionada (cond > 1e8) → invalidar con OLS, proceder con ridge
- Missing exposures > threshold → invalidar
- Varianza residual degenerada → invalidar
- corr_after ≈ 0 para exposiciones usadas en la regresión
- CV de lambda: lambda_used varía según cross-section
- weighted_ridge con pesos uniformes ≈ ridge sin pesos
- Huber downweights outliers: n_downweighted > 0 en datos contaminados
