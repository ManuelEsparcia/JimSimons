Especificación: labels/__init__.py

1. Propósito

Infraestructura compartida del paquete labels. Elimina ~400 líneas de código
duplicado entre los 5 submódulos. Proporciona capa de integración con
simons_core (graceful degradation si no disponible).

2. Jerarquía de errores (compartida)

LabelError (base)
  ├── ConfigError          configuración inválida
  ├── DataContractError    tabla de input viola contrato
  ├── QCFailure            check de severidad FAIL
  └── LeakageError         leakage temporal detectado

Antes: ConfigError definido 5 veces independientemente. Bug en 1 → 4 sin fix.

3. QCRecord (compartido)

QCRecord(check_name, severity, status, metric_value, message)
  .to_dict() -> JSON-serializable
  .to_gate_result() -> GateResult si simons_core disponible, dict si no

4. Integración simons_core

has_core() -> bool
get_logger(name) -> StructuredLogger | stdlib logger

Si simons_core disponible:
  RunContext, GateResult, Labels, MultiLabels, ContractViolation
  validate_schema, LABELS_SCHEMA, with_step, with_metric, log_gate_result

Si no disponible: todos = None. Código consumidor debe check con has_core().

to_multi_labels(df, asof_date, horizons, net_of_costs) -> MultiLabels | dict
  Bridge entre output de build_labels y ModelTrainer.fit.

validate_labels_output(df, asof_date=None) -> dict(passed, issues)
  Valida contra LABELS_SCHEMA con patterns y_fwd_ret_*d.

5. Utilities compartidas

Resolución de columnas:
  find_column(columns, candidates, required=True) -> str | None
  resolve_price_field(columns, semantic_field) -> str
  DATE_CANDIDATES, SYMBOL_CANDIDATES, UNIVERSE_FLAG_CANDIDATES, PRICE_FIELD_CANDIDATES

Transformación de datos:
  to_datetime(series) -> tz-naive midnight
  coerce_bool(series) -> bool con convenciones true/1/yes
  normalize_symbol(series) -> str upper stripped

I/O:
  load_mapping(path) -> dict (JSON/YAML)
  load_table(path) -> DataFrame | None (parquet/csv/feather/dir)
  write_frame(df, path) -> Path (parquet, fallback csv)
  write_json(payload, path) -> Path

Serialización:
  json_safe(value) -> JSON-serializable (numpy, pandas, Path, nan->None, inf->None)
  utc_now_iso() -> str
  hash_payload(payload) -> sha256
  fingerprint_path(path) -> sha256 basado en size+mtime
  optional_str(value) -> str | None
  optional_int(value) -> int | None
  optional_float(value) -> float | None

6. Invariantes

I1. Todas las funciones shared son drop-in replacement de las copias locales.
I2. json_safe(float('nan')) == None, json_safe(float('inf')) == None.
I3. find_column es case-insensitive.
I4. load_table con directorio concatena todos los parquet/csv encontrados.
I5. Graceful degradation: sin simons_core, todo funciona con stdlib equivalents.

7. Tests mínimos

- json_safe con np.nan, np.float64, np.int64, float('inf') -> None/value
- QCRecord.to_dict() serializable
- QCRecord.to_gate_result() devuelve dict si simons_core no disponible
- find_column case-insensitive match
- to_multi_labels produce MultiLabels o dict fallback
- validate_labels_output devuelve passed=True si schema no disponible
